## 🆘 Экстренная помощь

### Что-то пошло не так во время миграции!

1. **Не паникуйте!** Бэкап создан автоматически
2. **Проверьте логи:**
   ```bash
   docker compose logs api bot db
   ```
3. **Откатите миграцию:**
   ```bash
   ./scripts/rollback.sh
   ```
4. **Восстановите из бэкапа (если нужно):**
   ```bash
   docker compose exec -T db psql -U subscriptions_user -d subscriptions < backup_*.sql
   ```
5. **Изучите раздел Troubleshooting:**
   - [DOCKER_MIGRATION_GUIDE.md](DOCKER_MIGRATION_GUIDE.md) → Типичные ошибки
6. **Создайте issue** на GitHub с логами
