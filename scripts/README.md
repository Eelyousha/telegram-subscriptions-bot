# Скрипты миграции базы данных

Этот каталог содержит скрипты для безопасной миграции базы данных с int32 на int64 для telegram_id.

## 📁 Файлы

### `migrate.sh`
Основной скрипт для применения миграции с BigInteger (int64).

**Что делает:**
1. ✅ Проверяет статус контейнеров
2. ✅ Проверяет текущую версию миграции
3. ✅ Создает автоматический бэкап БД
4. ✅ Запрашивает подтверждение пользователя
5. ✅ Применяет миграцию
6. ✅ Перезапускает сервисы
7. ✅ Проверяет результат

**Использование:**
```bash
./scripts/migrate.sh
```

### `rollback.sh`
Скрипт для отката миграции обратно на Integer (int32).

**⚠️ ВНИМАНИЕ:** Откат невозможен, если есть telegram_id > 2,147,483,647

**Что делает:**
1. ✅ Проверяет возможность отката (макс. telegram_id)
2. ✅ Создает бэкап перед откатом
3. ✅ Запрашивает строгое подтверждение
4. ✅ Останавливает сервисы
5. ✅ Откатывает миграцию
6. ✅ Перезапускает сервисы

**Использование:**
```bash
./scripts/rollback.sh
```

## 🚀 Быстрый старт

### Применить миграцию

```bash
# 1. Сделать скрипт исполняемым (если еще не сделано)
chmod +x scripts/migrate.sh

# 2. Запустить миграцию
./scripts/migrate.sh

# 3. Следовать инструкциям на экране
```

### Откатить миграцию

```bash
# 1. Сделать скрипт исполняемым (если еще не сделано)
chmod +x scripts/rollback.sh

# 2. Запустить откат
./scripts/rollback.sh

# 3. Подтвердить, введя 'ROLLBACK'
```

## 📋 Требования

- Docker и Docker Compose установлены
- Контейнеры запущены (`docker compose up -d`)
- Права на выполнение скриптов (`chmod +x scripts/*.sh`)
- Bash shell (доступен на Linux, macOS, Git Bash на Windows)

## 🔧 Ручное выполнение команд

Если предпочитаете запускать команды вручную:

### Миграция
```bash
# Бэкап
docker compose exec db pg_dump -U subscriptions_user subscriptions > backup.sql

# Применить миграцию
docker compose exec api alembic upgrade head

# Проверить версию
docker compose exec api alembic current

# Перезапустить сервисы
docker compose restart api bot
```

### Откат
```bash
# Остановить сервисы
docker compose stop api bot

# Откатить
docker compose exec api alembic downgrade -1

# Проверить
docker compose exec api alembic current

# Запустить сервисы
docker compose start api bot
```

## 🐛 Troubleshooting

### Скрипт не запускается

```bash
# Проверить права
ls -l scripts/migrate.sh

# Если нет прав на выполнение
chmod +x scripts/migrate.sh
```

### "Permission denied"

```bash
# Запустить с sudo (Linux)
sudo ./scripts/migrate.sh

# Или дать права текущему пользователю на Docker
sudo usermod -aG docker $USER
# После этого нужно перелогиниться
```

### "No such service: api"

```bash
# Проверить имена контейнеров
docker compose ps

# Отредактировать скрипт с правильными именами
```

### Скрипт зависает на подтверждении

```bash
# Просто введите 'yes' и нажмите Enter
Продолжить? (yes/no): yes

# Для отката введите 'ROLLBACK'
```
